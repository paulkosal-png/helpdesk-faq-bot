# New hire IT checklist

## Day one
1. Sign in to your laptop with the temporary password from your welcome email, then set a new password.
2. Set up MFA with an authenticator app.
3. Sign in to email, calendar, and Slack. Join #it-help and #general.
4. Install any extra approved apps from Self Service / Company Portal.

## First week
- Connect to the VPN once from home to confirm it works.
- Add the office printer.
- Complete the security awareness training assigned to you.

## Getting help
Ask this bot first, then post in #it-help.
