# VPN troubleshooting guide

## Before you start
You only need the VPN for internal file shares, the wiki, and admin tools. Email, Slack, and video calls work without it.

## Common errors
- **Authentication failed**: your password may have expired. Reset it in the self-service password portal, then try again.
- **MFA timed out**: approve the push notification within 60 seconds, or use the 6-digit code instead.
- **Connected but nothing loads**: disconnect, switch gateways (Primary/Backup), and reconnect. Hotel and airport Wi-Fi often block VPNs; try a phone hotspot.
- **Slow when connected**: large uploads should go directly to the cloud drive, not over the VPN.

## Collecting details for IT
Take a screenshot of the error, note the time, gateway, and your network (home, hotel, hotspot), and post it in #it-help.
