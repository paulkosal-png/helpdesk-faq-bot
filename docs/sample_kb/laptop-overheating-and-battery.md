# Laptop overheating, fan noise, and battery health

## Symptoms
A loud fan, a hot keyboard, or the laptop slowing down under load usually means it is thermal throttling.

## Quick fixes
- Use the laptop on a hard, flat surface - beds and couches block the air vents.
- Quit heavy apps you are not using (video editors, 3D tools, dozens of browser tabs).
- Check Activity Monitor (Mac) or Task Manager (Windows) for a process using high CPU and quit it.
- Restart the laptop to clear stuck background processes.
- Install pending OS updates; firmware updates often include fan and power fixes.

## Battery health
- Mac: System Settings > Battery > Battery Health. Windows: run `powercfg /batteryreport`.
- If the battery is swollen (the case bulges or the trackpad clicks poorly), stop using it and contact IT immediately. Swollen batteries are a fire hazard.

## When to contact IT
If the fan stays loud with nothing running, or the laptop shuts down from heat, post in #it-help so we can schedule a hardware check or a loaner.
